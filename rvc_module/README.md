# RVC — Realizable Vulnerability Correlator

Сопоставляет результаты внешнего сканирования (атакующий) с внутренней
конфигурацией стенда (Trivy + инвентаризация ПО) и **детерминированно**
определяет, какие уязвимости реально воспроизводимы. Выдаёт по каждой
карточку с цепочкой MITRE (CVE/CWE/CAPEC/ATT&CK), разбором «почему такой
вердикт» и пошаговым плейбуком.

Назначение — учебная лаборатория: студент видит эталон реальных уязвимостей
стенда, обоснование и сценарий воспроизведения.

## Принципы

- Вердикт «реализуемо/нет» — только правила, без ML и без сети (воспроизводимо).
- Факты MITRE — из локального среза `rvc/mitre_kb.json` (офлайн).
- Полная трасса решения по каждой находке (5 проверок).

## Движок: 5 проверок

1. **Достижимость** — порт открыт снаружи и подтверждён в конфигурации сервера.
2. **Сервис активен** — баннер/флаг/служба подтверждают рабочий сервис.
3. **Уязвимая версия/продукт** — версия ОС или продукт попадают в уязвимый диапазон CVE.
4. **Компенсирующие контроли** — брандмауэр/антивирус и т.п.
5. **Тяжесть/уверенность** — severity и итоговая уверенность.

Вердикт: `realizable` / `partially` / `not_realizable`.

## Структура

```
rvc/
  models.py        структуры данных
  loaders.py       парсинг attacker / trivy / scan_history -> ScanContext
  knowledge.py     доступ к локальному срезу MITRE
  mitre_kb.json    срез CVE/CWE/CAPEC/ATT&CK
  engine.py        движок 5 проверок (ядро)
  enrichment.py    обогащение MITRE + плейбук
  pipeline.py      оркестратор + CLI
app.py             веб-сервер (Flask)
web/index.html     дашборд
```

## Запуск

CLI (отчёт в JSON):

```
python -m rvc.pipeline --base . --out report.json
```

Веб-дашборд:

```
pip install -r requirements.txt
python app.py
```

Открыть http://127.0.0.1:5000

## Вход

- `data/trivy_scan_*.json` — уязвимости пакетов (берётся самый свежий).
- `data/scan_history/scan_*.json` — инвентаризация стенда (самый свежий).
- `history/**/*.json` — внешние сканы атакующего (объединяются все).

## Расширение базы MITRE

`rvc/mitre_kb.json` — curated-срез под сущности стенда. Пополняется из
официальных фидов NVD/CWE/CAPEC/ATT&CK; CVE без записи помечаются как
требующие ручной проверки (вердикт `partially`).
