# 🖥️ Настройка и запуск графического интерфейса (GUI)

## 📋 Требования

- Python 3.8+
- Установленные зависимости основного проекта (см. `requirements.txt`)
- Дополнительные зависимости для GUI (устанавливаются автоматически)

## 🚀 Быстрый старт

### 1. Установка зависимостей GUI

```bash
pip install -r gui/requirements.txt
```

Или автоматически при запуске:

```bash
python gui/run_gui.py
```

### 2. Запуск GUI

```bash
python gui/run_gui.py
```

### 3. Открыть в браузере

Перейдите по адресу: **http://localhost:5000**

## 🎯 Возможности GUI

### Панель управления
- **Парсинг** - скачивание и обработка баз данных MITRE (CAPEC, CWE, CVE, ATT&CK)
- **Связывание** - установление перекрестных ссылок между базами
- **AI обогащение** - заполнение пустых полей с помощью ИИ
- **Перевод** - перевод выбранных полей на русский язык

### Редактор баз данных
- Просмотр всех 4 баз данных
- Поиск и фильтрация записей
- Редактирование полей
- Пагинация

### Кэш переводов
- Просмотр всех переводов
- Редактирование и удаление записей
- Очистка кэша

### Настройки
- Конфигурация сервиса перевода (Google/Yandex)
- Настройка параметров перевода
- AI настройки (Ollama/OpenAI)

## 🔧 Интеграция с основным проектом

GUI автоматически:
- Использует конфигурацию из `src/config.py`
- Запускает скрипты из `src/` (step1_parse.py, step2_link.py, etc.)
- Работает с данными из папки `output/`

## ⚠️ Важные замечания

1. **Первый запуск**: Перед использованием редактора баз данных необходимо выполнить парсинг (кнопка "Парсинг" на панели управления)

2. **Изменение настроек**: Изменения в настройках GUI не обновляют `config.py` автоматически. Для применения настроек нужно:
   - Либо изменить `src/config.py` вручную
   - Либо использовать консольное меню (`python src/menu.py`)

3. **Остановка GUI**: Нажмите `Ctrl+C` в терминале

4. **Порт**: Если порт 5000 занят, измените его в `gui/run_gui.py`:
   ```python
   socketio.run(app, host='0.0.0.0', port=8080, debug=False)
   ```

## 🆘 Решение проблем

### GUI не запускается
Проверьте, установлены ли зависимости:
```bash
pip install Flask Flask-SocketIO Flask-CORS eventlet
```

### Ошибки при запуске процессов
Убедитесь, что основной проект настроен корректно:
```bash
python src/main.py
```

### Не отображаются базы данных
Проверьте наличие файлов в папке `output/`:
- capec_database.json
- cwe_database.json
- cve_database.json
- mitre_attack.json

Если файлов нет, запустите парсинг через GUI или консоль.

## 📞 Поддержка

При возникновении проблем:
1. Проверьте логи в консоли
2. Проверьте логи в GUI (панель "Логи процессов")
3. Убедитесь, что все зависимости установлены
